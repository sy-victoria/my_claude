# M9a：todo 工具

日期：2026-07-13

## 做了什么

复现 TodoWrite：`todo_write` 工具让模型维护任务清单（pending/in_progress/completed），CLI 实时渲染。新增 `minicode/tools/todo.py`，`prompts.py` 加了"3 步以上任务先列清单"的指引。

## 关键设计

这个工具不操作外部世界，操作的是**模型自己的工作记忆**：每次更新清单，清单内容会以 tool_result 的形式回到上下文里，等于模型在给自己写提示词——长任务中反复被提醒"还剩什么没做"。这是"用工具机制实现自我提示"的一个巧妙模式，成本极低但显著降低多步骤任务的遗忘率。

采用覆盖式更新（每次传完整清单）而不是增量修改——简单，且模型每次都被迫重新审视全部任务。
